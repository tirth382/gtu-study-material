⚠️ PDF Viewing / Downloading Issues (Fix)

Sometimes, GitHub's built-in PDF viewer takes too long to load or fails to open the document. If you face any issues viewing the PDFs directly on GitHub, follow these steps:

Method : Download the Raw File (Recommended)
1. Click on the PDF file you want to open.
2. Look for the **"Download raw file"** button (an icon with a downward arrow ⬇️) on the top right side of the file viewer.
3. Click it to download the PDF directly to your PC or mobile.
